# Sticker Maker catalog

Sticker packs offered in the **Discover** tab of the Sticker Maker app. Published with
`catalog-tools/publish.js`; do not edit by hand.

- `catalog/v1/catalog.json` lists the packs.
- `catalog/v1/packs/<pack>/<version>/` holds each pack's 512 px WEBP stickers, thumbnails and tray icon.
- `catalog/v1/licences/` holds the licences of the artwork.
